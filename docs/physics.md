# 模型、推导与叙事修正

本片采用均匀、理想、无阻尼、恒定预张力弦的小振幅模型，讨论已建立的单一简正模；不讨论驱动建立过程、损耗或非线性。下列推导独立核算，原 `plan.md` 只提供问题框架。

## 1. 符号和振动模式

用 τ 表示张力，用 T₀ = 2π/ω 表示周期，避免同一个 T 表示两个物理量。

\[
y=A\sin(kx)\cos(\omega t),\quad k=\frac{n\pi}{L},\quad
v=\sqrt{\tau/\mu},\quad\omega=vk,\quad f_n=\frac{nv}{2L}.
\]

片中 n = 2，因此 λ = L。波节在 x = 0、L/2、L，波腹在 L/4、3L/4。相邻波节距 λ/2，波节至相邻波腹距 λ/4。图像纵向放大、时间慢放，不据屏幕斜率解释真实参数。

## 2. 能量密度

\[
U=\tfrac12\mu\omega^2A^2,\qquad
u_k=U\sin^2(kx)\sin^2(\omega t),\qquad
u_p=U\cos^2(kx)\cos^2(\omega t).
\]

u、U 的单位为 J/m。由小斜率展开，弦微元的附加长度为约 (yₓ²/2)dx，因而 uₚ = τyₓ²/2。势能取决于局部伸长，并不由该点的横向位移直接决定。

- ωt = 0：弦的各点位移达到各自极值，速度为零；势能密度在波节处最大，波腹处为零。
- ωt = π/2：弦经过平衡位置，斜率为零；全部为动能，动能密度在波腹处最大。
- ωt = π/4 + mπ/2：总能量密度处处为 U/2。
- 时间平均总密度 ⟨u⟩ = U/2，空间均匀。

总密度也可写为

\[
u=\frac U2[1+\cos(2kx)\cos(2\omega t)].
\]

全弦总能量 E = UL/2 = μω²A²L/4 不变。说“每隔四分之一周期交换分布”，不应理解为所有能量都集中于一个数学上的点；更不意味着任意位置始终发生局部动能与势能的一对一转换。

## 3. 瞬时能流与局部守恒

取朝 +x 方向为正，穿过截面的功率为

\[
P=-\tau y_x y_t
=\frac{\tau A^2k\omega}{4}\sin(2kx)\sin(2\omega t).
\]

**原计划的 1/2 系数应改为 1/4**，因为 sin(kx)cos(kx) 和 sin(ωt)cos(ωt) 分别贡献一个 1/2。P 单位为 W，是一维弦的截面功率。

\[
\partial_tu=-U\omega\cos(2kx)\sin(2\omega t),\qquad
\partial_xP=U\omega\cos(2kx)\sin(2\omega t).
\]

于是 ∂ₜu + ∂ₓP = 0。对任意固定小区间 [a,b] 积分，得到

\[
\frac{d}{dt}\int_a^b u\,dx=P(a,t)-P(b,t).
\]

波节和波腹处的 P 始终为零；相邻波节与波腹之间各自构成一个总能量守恒的小区间，其内部发生重分布。这里“λ/4 尺度的往返”不是说一个可标记的能量粒子跨越整段弦，也不是说能量穿过波腹流入下一个区间。

在 0 < ωt < π/2 内，从每个波节附近向相邻波腹附近流动：内波节有左右两侧，不能统一叙述成“向右”。后一个四分之一周期方向反转。⟨P⟩ = 0，但瞬时 P 通常不为零。

## 4. 两列行波的解释：交叉项抵消

\[
y_+=\frac A2\sin(kx-\omega t),\qquad
y_-=\frac A2\sin(kx+\omega t),\qquad y=y_++y_-.
\]

令 C = τA²kω/4，则

\[
P_+=C\cos^2(kx-\omega t),\qquad
P_-=-C\cos^2(kx+\omega t).
\]

各行波瞬时能流不恒定，时间平均才是 ±C/2 = ±τA²kω/8。在同一 (x,t) 处，两个瞬时功率不必抵消。

将总位移代入能流，交叉项为

\[
P_\text{cross}=-\tau(y_{+,x}y_{-,t}+y_{-,x}y_{+,t})=0,
\]

因为 y₊,ₜ = −v y₊,ₓ，而 y₋,ₜ = +v y₋,ₓ。因此

\[
P=P_++P_-
=C[\cos^2(kx-\omega t)-\cos^2(kx+\omega t)]
=C\sin(2kx)\sin(2\omega t).
\]

**原计划“瞬时能流来自干涉交叉项”的说法不成立。** 这里是两个随时间变化的分量功率相加；平均值抵消，不等于瞬时值恒相消。总能量密度的动能和势能交叉项也互相抵消。

## 5. 相位与比较

同一个波节区间内，sin(kx) 同号，振动同相；相邻区间异号，时间振动相差 π。波节振幅为零，相位不定义。“0 / π”指相对于共同时间因子的空间相位差，而非各点绝对时间相位不变化。

单一理想驻波没有整体向前移动的相位图样，也不是一个窄带传播波包，因此不直接为它断言“相速度、群速度都为零”。构成它的行波仍以 ±v 传播。

三方比较中的“行波”限定为本模型中的单向简谐行波：其 uₖ = uₚ 在每个时空点成立，但两者的值随相位变化；其平均能流为非零常数，瞬时能流并非常数。瞬时能量密度也不处处均匀。比较简谐振子时，讨论的是单个振子自身的能量，不把弦中一个任意微元等同于孤立振子。

## 6. 验证与参考

`scripts/check_physics.py` 用独立的位移导数计算能量与功率，检查总能量、四分之一波长区间能量、时均密度、时均能流、边界与内部零能流截面、均匀密度时刻、有限差分连续性方程、行波功率叠加和交叉项，共 11 项。参数及误差保存在 `build/physics_checks.json`。

核对资料（内容采用独立推导与原创表述）：

- [David Morin，Transverse Waves on a String](https://davidmorin.physics.fas.harvard.edu/files/2023/11/waves_transverse.pdf)：弦波能量与驻波功率；明确区分瞬时能流与时间平均。
- [ČVUT，Waves solved exercises，习题 5.7](https://kf.fjfi.cvut.cz/~schmidt/en/waves/VOAF_solved_exercises.pdf)：反向传播弦波的能流可加，交叉项消失。
