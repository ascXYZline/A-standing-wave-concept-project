# 2026-10-29 视觉与讲解层次优化

本次不改变物理模型和原有研究主线，保留无声字幕形式。

## 画面节奏

- 保留深色背景和青／橙／绿主色。青色对应动能或右行波，橙色对应势能或需要关注的中间项，绿色对应总量与结论，紫色区分左行波与反相区间。
- 品牌、细分隔线与进度条在场景之间保留。正文短距离淡出，下一问题轻微上移淡入，避免整页硬切。
- 一段讲解只引入当前需要的信息。公式、曲线、标记和结论依次出现；比较页逐列揭示，焦点边框平滑移到下一列。
- 物理振动以线性时间推进，说明性定位和公式移动采用缓入缓出。关键状态平滑停住后保留阅读时间。

## 推导的分层呈现

| 内容 | 新的观看顺序 |
| --- | --- |
| 位移模型 | 观察固定波节 → 标出 λ/4 → 分别提示位置因子和时间因子 |
| 相位 | 先跟踪行波波峰 → 再引入驻波取样点 → 显示同相与反相 |
| 能量密度 | 定义 → 对位移求导 → 平方并代入 → 依次显示动能、势能曲线 |
| 特别时刻 | 慢放到 ωt = π/4 → 时间因子变成 1/2 → 空间平方和变成 1 → 得到 U/2 |
| 能流 | 横向力乘横向速度 → 代入导数 → 两次使用二倍角 → 得到系数 1/4 |
| 守恒 | 高亮一小段弦 → 流入减去流出 → 积分形式 → 缩小区间得到连续性方程 |
| 行波叠加 | 分别显示两列波 → 显示叠加结果 → 看瞬时功率 → 取平均 → 展开交叉项并抵消 |

公式使用保留相同项的变换，原位转换符号。重点项配合一次轻微强调或框选，避免长距离飞动。新增六个短片段，主要用于推导过程和停顿，不添加重复旁白。

## 技术与校验

所有字幕起止时间均由实际动画时钟生成。原版材料保存在 `archive/v1/`。

修复 Manim 0.18.1 中组合淡入后部分动态图形可能保持暂停更新的问题：淡入完成后显式恢复对象的更新器。`scripts/check_animation.py` 验证波形能够从极值运动到平衡位置、继续振动并正常淡出，防止视觉动画与公式状态脱节。

完整导出继续检查：11 项物理数值验证、动态图形回归检查、36 段字幕及九个章节时间、1080p30 编码、无音轨，以及全片解码。最终画面采样见 `output/storyboard.jpg` 与 `build/final-sheet.jpg`。
